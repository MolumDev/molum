# Telegram‑бот Molum 🚀

Добро пожаловать в репозиторий асинхронного Telegram‑бота для криптопроекта **Molum**. Этот бот предназначен для управления сообществом до и после листинга: раздаёт баллы за подписку на официальный канал, рефералов и выполнение различных заданий, интегрируется с **Supabase (PostgreSQL)** и поддерживает **Solana Mini App** интеграцию.

## 🛠 Технологический стек

* **Python 3.10+** (протестировано на Python 3.13)
* **aiogram 3.x** — современный асинхронный фреймворк для Telegram Bot API.
* **Supabase Python SDK** (`supabase`) — клиент для работы с Postgres базой данных через Service Role Key.
* **SQLite (встроенный)** — локальный автоматический **резервный режим (fallback)** на случай отсутствия Supabase ключей, что позволяет мгновенно тестировать бота локально без настройки облачной БД!
* **AIOHTTP** — для работы асинхронного Webhook сервера при деплое в продакшн.
* **python-dotenv** — для управления конфигурацией через `.env` файл.

## 🗄 Настройка базы данных (Supabase)

Чтобы настроить базу данных Supabase, выполните следующие шаги:

1. Перейдите в панель управления [Supabase](https://supabase.com/) и создайте новый проект.
2. Откройте раздел **SQL Editor** в левом меню вашего проекта.
3. Нажмите **New query** (Создать новый запрос).
4. Скопируйте содержимое файла `schema.sql` из этого репозитория и вставьте его в текстовое поле.
5. Нажмите кнопку **Run** в правом нижнем углу.

### Что делает миграция `schema.sql`:
* Создаёт таблицы:
  * `profiles` — профили пользователей, баллы, язык, статус подписки на канал, кошелёк.
  * `referrals` — логи реферальных связей и начисленных наград.
  * `tasks` — база данных активных заданий бота (по умолчанию: подписка на канал, приглашение 3 друзей, подключение кошелька).
  * `user_tasks` — состояние выполнения конкретных задач каждым пользователем.
  * `settings` — глобальные настройки бота (`token_status`, `listing_date`).
  * `token_notifications` — реестр пользователей, запросивших уведомление при старте листинга.
* Создаёт триггер для автоматического обновления поля `updated_at` в `profiles`.
* Создаёт специальную безопасную хранимую процедуру (RPC) `clean_database()`, которая позволяет администраторам безопасно и быстро очищать всю базу данных (cascade truncate) прямо из админ-панели Telegram.

## ⚙️ Переменные окружения (.env)

Создайте файл `.env` в корневой папке проекта на основе предоставленного шаблона `.env.example`:

```env
# Токен вашего бота от Telegram @BotFather
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Юзернейм официального канала для проверки подписки (обязательно с '@')
CHANNEL_USERNAME=@molum

# Ссылка на хостинг вашего Solana Mini App
MINI_APP_URL=https://molum-miniapp.vercel.app

# ID администраторов через запятую (для доступа к /admin)
ADMIN_IDS=123456789,987654321

# URL и Service Role Key от Supabase (Project Settings -> API)
# Если оставить эти поля пустыми, бот автоматически переключится на встроенную SQLite базу данных!
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

# Конфигурация для вебхуков (Заполняется только при деплое на Render/Heroku. Для локального тестирования оставьте пустыми)
# WEBHOOK_URL=https://your-deployed-app.onrender.com
# PORT=8080
```

## 🚀 Установка и запуск локально

### Шаг 1. Клонирование и подготовка
Убедитесь, что у вас установлен Python версии 3.10 или выше.

```bash
# Установите зависимости из файла requirements.txt
pip install -r requirements.txt
```

### Шаг 2. Проверка импортов и синтаксиса
Запустите диагностический скрипт, чтобы убедиться, что все зависимости и модули работают исправно:
```bash
python3 test_imports.py
```

### Шаг 3. Запуск бота
Если в файле `.env` переменная `WEBHOOK_URL` закомментирована или пуста, бот запустится в автоматическом режиме **Polling (длинные опросы)**, что идеально подходит для локальной разработки:

```bash
python3 bot.py
```

## 🎮 Функционал и сценарии работы

### 🌐 Мультиязычность
Бот автоматически определяет язык интерфейса пользователя при первом нажатии `/start` (на основе его настроек в Telegram — EN или RU). В дальнейшем пользователь может вручную переключить язык в меню `🌐 Язык`. При переключении:
1. Запись в БД `language_code` мгновенно обновляется.
2. Предыдущее интерактивное сообщение редактируется на новом языке с обновленными кнопками.
3. Бот присылает обновленное Reply-меню (кнопки главного меню) на выбранном языке.

### 👥 Реферальная система
* Бот генерирует уникальные реферальные ссылки вида `https://t.me/MolumBot?start=ref_<telegram_id>`.
* При переходе по ссылке новый пользователь видит приветствие и предложение подписаться на канал.
* Происходит **защита от само-рефералов** (пользователь не может пригласить самого себя).
* Баллы за реферала (**+50 Points**) начисляются пригласителю только **после того, как приглашённый пользователь успешно проверит подписку на официальный канал**. Это исключает накрутку ботами без реальной подписки! При этом оба пользователя получают уведомление о начислении.

### 🧹 Чистота чата (Clean Chat)
* Все интерактивные Inline-клавиатуры бота имеют кнопку **«❌ Удалить»** (или «❌ Delete»), которая мгновенно удаляет сообщение бота.
* Временные сервисные оповещения (например, уведомления о спаме, ошибки авторизации, а также уведомления о подключении кошелька) удаляются автоматически через `bot.delete_message` с задержкой 2-5 секунд с помощью асинхронных фоновых задач `asyncio.create_task`, гарантируя чистоту и аккуратность чата!

### 🛑 Защита от спама (Anti-Spam Throttling)
Встроенный middleware отслеживает частоту команд от каждого пользователя. Ограничение составляет **1 запрос в секунду**. В случае спама бот высылает предупреждение и автоматически удаляет его через 2.5 секунды, не нагружая чат и сервера.

## 📱 Интеграция с Mini App (Web App)

Бот поддерживает двустороннее общение с Mini App.

### 1. Открытие страниц Mini App
Бот отправляет специальные кнопки для открытия вашего Web App:
* Кнопка **«Открыть в Mini App»** в меню `/leaderboard` передаёт параметры ID пользователя и язык для отображения статистики: `{MINI_APP_URL}/?page=leaderboard&tg_id={id}&lang={lang}`.
* Кнопка **«Подключить кошелёк»** в меню `/wallet` открывает страницу подключения кошелька: `{MINI_APP_URL}/wallet?tg_id={id}&lang={lang}`.

### 2. Приём данных из Mini App (WebAppData)
Когда ваше Mini App вызывает метод Telegram SDK `Telegram.WebApp.sendData(JSON_STRING)`, бот асинхронно перехватывает это событие. Ожидаются два типа JSON-пакетов:

#### А. Подключение Solana-кошелька:
```json
{
  "type": "wallet",
  "address": "4k3DyjzvN2Xn9K69zFf...solana_address"
}
```
* **Реакция бота:** Бот сохраняет Solana-адрес в профиле пользователя в БД, автоматически закрывает / отмечает выполненной задачу `connect_wallet`, начисляет бонусные **200 баллов** (если задача ещё не выполнялась), отправляет красивое уведомление и автоматически удаляет сервисное сообщение WebApp через 5 секунд!

#### Б. Проверка выполнения кастомной задачи:
```json
{
  "type": "task_check",
  "task_id": "invite_3_friends"
}
```
* **Реакция бота:** Бот проводит аналогичную серверную валидацию (например, проверяет, пригласил ли пользователь действительно 3 друзей) и начисляет награду.

## 👑 Админ-панель (`/admin`)

Доступ к панели администрирования имеют только пользователи, чьи Telegram ID перечислены в переменной `ADMIN_IDS` в `.env`.

### Возможности админ-панели:
1. **📊 Статистика** — отображает количество зарегистрированных пользователей, общее число рефералов и сумму всех баллов в обращении.
2. **👥 Просмотр пользователей** — отображает список последних 20 пользователей, их баллы и даты регистрации.
3. **✏️ Ручное изменение баллов** — позволяет начислить или списать баллы у любого пользователя по его Telegram ID (формат: `<telegram_id> <изменение_баллов>`).
4. **📢 Массовая рассылка** — рассылает текстовое сообщение всем пользователям из базы данных с итоговым отчётом об успешных и неудавшихся доставках.
5. **🚀 Изменение статуса токена** — переключение статуса токена между `pre-launch` (с обратным отсчетом до даты листинга) и `live` (с отображением цены и ссылки на DexScreener). Также позволяет установить новую ISO дату листинга.
6. **🧹 Очистка БД** — запрашивает двойное подтверждение. В случае согласия производит каскадную очистку всех таблиц в Supabase или SQLite (TRUNCATE CASCADE) и сбрасывает автоинкрементные последовательности.

## ☁️ Деплой на хостинг

Проект полностью готов для деплоя на любые облачные платформы: **Render, Heroku, Railway, PythonAnywhere, VPS**.

### Инструкция для Render / Heroku:
1. Загрузите код в ваш приватный/публичный репозиторий GitHub.
2. Создайте новый **Web Service** на Render.
3. Укажите следующие параметры сборки:
   * **Runtime:** `Python`
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `python3 bot.py`
4. В разделе **Environment Variables** добавьте переменные:
   * `BOT_TOKEN`
   * `ADMIN_IDS`
   * `CHANNEL_USERNAME`
   * `SUPABASE_URL`
   * `SUPABASE_SERVICE_KEY`
   * `PORT` (автоматически выставляется Render, обычно `10000`)
   * `WEBHOOK_URL` — укажите URL вашего созданного сервиса, например: `https://molum-bot.onrender.com`
5. Сохраните настройки. Бот автоматически распознает наличие `WEBHOOK_URL`, отключит Polling и запустит высокопроизводительный вебхук-сервер на указанном порту!
